# Modern Calculator

A simple, responsive calculator built with **HTML5, CSS3, Bootstrap 5, and JavaScript**. This project is a practical exercise in front-end development, user interface design, accessibility, and testing.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division.
- Clear button to reset the display.
- Responsive layout for desktop and mobile devices.
- Modern dark theme with cyan accents.
- Bootstrap grid and utility classes.
- Semantic HTML structure and accessibility improvements.
- Custom CSS variables for maintainable styling.

## Technologies

- **HTML5** — semantic page structure.
- **CSS3** — custom styling, design tokens, and responsive adjustments.
- **Bootstrap 5.3.3** — grid system and utility classes, loaded via CDN.
- **JavaScript** — calculator interactions and arithmetic logic.

## Getting Started

### Run locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Make sure you have an internet connection so Bootstrap can load from its CDN.

No additional package installation is required.

## Accessibility

The project aims to improve accessibility through:

- A main landmark for the primary content.
- An accessible label for the calculator display.
- Clear keyboard focus indicators.
- Readable text and button labels.
- Responsive layouts for different screen sizes.

Accessibility should also be verified with Lighthouse and manual keyboard and screen-reader testing.
